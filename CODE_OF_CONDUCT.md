# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, criticize ideas rather than people, and no harassment of any kind.
This applies in issues, pull requests, discussions and anywhere you represent the project.

## Reporting

Report unacceptable behavior privately to the maintainer through GitHub: the
[Security → Report a vulnerability](../../security/advisories/new) form also accepts conduct reports, or contact
the repository owner through their GitHub profile. Reports are kept confidential.

The maintainer may remove comments, commits or other contributions that break this code, and may block
repeat offenders.
