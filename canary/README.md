# humanloads-canary

Calibration package for [humanloads](https://github.com/zenyadar/humanloads). It does nothing; please don't install it.

A new patch version is published once a week. Nobody uses this package, so every download it gets
is bot/mirror noise: registry mirrors, security scanners, crawlers. humanloads uses these numbers
to measure that noise and subtract it from the download counts of real packages.
